# CRM Web Application

The main CRM application for sales representatives and managers.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript 5
- TailwindCSS 3
- Shadcn/ui
- React Query 5
- Zustand 4

## Modules

- [ ] Dashboard & KPIs
- [ ] Customer Management
- [ ] Contact Management
- [ ] Lead Pipeline
- [ ] Opportunity Board (Kanban)
- [ ] Task Manager
- [ ] Calendar & Scheduling
- [ ] Document Manager
- [ ] Reports & Analytics
- [ ] AI Chat Interface

## Getting Started

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000)
