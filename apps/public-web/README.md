# Public Website

Marketing and public-facing website for the Enterprise AI CRM platform.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript 5
- TailwindCSS 3

## Pages

- [x] Landing page
- [x] Features
- [x] Pricing
- [x] Contact
- [x] Login / Sign Up entry points (link to the CRM app)
- [ ] Blog

## Getting Started

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Open [http://localhost:3003](http://localhost:3003)
